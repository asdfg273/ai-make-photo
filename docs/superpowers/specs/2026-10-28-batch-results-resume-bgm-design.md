# 批量结果、断点续跑与视频配乐设计

日期：2026-10-28

## 目标与边界

本轮完成三个相互衔接但可独立验证的功能：

1. 批量出图结束后可按“角色 → 场景 → 序号”查看结果和缩略图，并把选中的图片发送到图生图精修。
2. 用 `jobs.json` 持久化逐张任务，关闭或崩溃后可继续未完成任务，不重复已成功的图片。
3. 在视频配音区选择或清除背景配乐，使已有 FFmpeg 混音分支收到真实文件路径。

不重写生成链路，不引入新的任务线程，不批量重命名或移动原始输出，不改变既有 `BatchRunner` 信号签名。

## 方案选择

采用“独立结果视图 + 逐张持久化清单”。相比只读取 `Scene.output_paths`，它能保留每张图的序号和状态；相比扫描输出目录推测归属，它不会混入其他生成任务的文件。

## 组件与数据流

### `utils/batch_jobs.py`

新增 `BatchJobStore`，默认清单位于场景库同目录的 `jobs.json`（正常项目为 `data/jobs.json`）。文件结构：

```json
{
  "version": 1,
  "sessions": {
    "character-uuid": {
      "character_uuid": "character-uuid",
      "character_name": "角色名",
      "created_at": "ISO-8601",
      "updated_at": "ISO-8601",
      "jobs": [
        {
          "scene_uuid": "scene-uuid",
          "scene_name": "场景名",
          "index": 0,
          "status": "pending",
          "error": "",
          "output_paths": []
        }
      ]
    }
  }
}
```

每个角色的最近一次批量队列独立保存。写入采用临时文件替换，读取损坏文件时返回空会话并记录错误，不阻断对话框。读取续跑信息时把上次遗留的 `running` 归一为 `pending`。

### `utils/batch_runner.py`

- 新任务开始时建立完整清单，保持现有场景展开顺序。
- 每次派发将对应项标为 `running`；收图后保存该张的输出路径并标为 `done`；失败记录错误。
- 用户停止时，当前未完成项恢复为 `pending`，其余未派发项保持 `pending`。
- `resume(character, scenes)` 按场景 UUID 找回仍存在的场景，只把非 `done` 项重新入队；已成功项及其路径保留用于结果页。
- 续跑进度以完整清单为总数，以此前已成功数为初始完成数。删除的场景无法续跑，其余任务仍可继续。

### `ui/batch_result_view.py`

新增独立 QWidget：

- 左侧 QTreeWidget 按角色、场景、第 N 张分三层展示；每个叶节点绑定输出路径和状态。
- 右侧 QLabel 按比例显示所选图片缩略预览，并显示文件名或缺失提示。
- 只有状态为 `done` 且文件存在时启用“发送到图生图精修”。
- 通过 `send_requested(str)` 发出路径，不直接依赖主窗口，便于离屏测试。

### `ui/scene_batch_dialog.py`

对话框改为“场景设置”和“批量结果”两个页签，保留现有控件属性名和运行信号。打开、单场景完成、整批结束及续跑状态变化时刷新结果页。

“继续未完成场景”按钮显示待跑数量；没有未完成项时禁用。续跑不依赖当前勾选状态，因为队列归属以清单为准。发送精修调用 `shell.send_path_to_img2img(path)`；任务未运行时关闭对话框，让用户直接看到图生图页面。

### 视频配乐

在 `ui/pages/video_page.py` 的配音区添加：

- `chk_bg_music`：启用背景配乐。
- `txt_bg_music_path`：只读路径框。
- 选择、清除按钮，分别连接 `_pick_bg_music` 和 `_clear_bg_music`。

`ui/video_panel_mixin.py` 使用文件对话框选择常见音频格式，路径收集改为读取 `txt_bg_music_path.text()`。只有启用配音、勾选配乐且路径存在时写入 `voice_params["bg_music"]`，沿用现有混音逻辑。

## 多语言与可访问性

新增静态和动态文案使用 `ui_i18n.tr/trf`，词典提供中文原文、英文和日文。按钮具有明确文字，路径框只读避免无效手动输入，图片缺失时禁用精修而不是弹出无意义错误。

## 错误处理

- 清单损坏或不可写：记录日志；生成可继续，但续跑按钮没有可用清单时保持禁用。
- 输出文件被移动或删除：结果项保留，预览显示缺失，精修按钮禁用。
- 场景被删除：忽略该场景的续跑项，不让整个恢复过程失败。
- 配乐路径不存在：不写入 `bg_music`，避免把无效路径送入 FFmpeg。
- 宿主缺少 img2img 桥接：状态区提示，不清空结果。

## 验证

新增离屏/临时目录测试：

1. 清单创建、逐张状态与输出路径原子持久化，重载后内容一致。
2. `running` 恢复为待跑，已完成项不重复入队，续跑保留历史输出。
3. 结果视图层级、序号、预览选择和精修信号路径正确。
4. 对话框能发现未完成项并调用 Runner 续跑。
5. 视频页配乐控件存在，选择/清除路径正确，参数收集能透传真实路径。
6. 新增词条均有英日翻译，相关旧回归测试保持通过。
